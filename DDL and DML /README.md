# DDL and DML - SQL Practice
## DDL - Data Definition Language

DDL is used to create and modify the structure of database objects.

### Commands Covered
- CREATE
- ALTER
- DROP
- TRUNCATE

## DML - Data Manipulation Language

DML is used to work with data stored in database tables.

### Commands Covered
- INSERT
- UPDATE
- DELETE

## What I Practiced

- Creating database tables
- Modifying table structure
- Inserting data
- Updating data
- Deleting data

## Tool Used

- MySQL
