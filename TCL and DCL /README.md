# TCL & DCL - SQL Practice

## Overview

This practice covers Transaction Control Language (TCL) and Data Control Language (DCL).

## TCL - Transaction Control Language
TCL commands are used to manage transactions in a database.

### Commands Covered
- COMMIT
- ROLLBACK
- SAVEPOINT

## DCL - Data Control Language
DCL commands are used to control access and permissions in a database.

### Commands Covered
- GRANT
- REVOKE

## What I Practiced
- Managing database transactions
- Committing and rolling back transactions
- Creating savepoints
- Granting database permissions
- Revoking database permissions

## Tool Used
- MySQL
